# History

Documents kept for context. **They describe earlier plans or designs**, not
the code as it is. For the current design see
[../ARCHITECTURE.md](../ARCHITECTURE.md), [../SPEC-v3.md](../SPEC-v3.md) and
[../DECISIONS.md](../DECISIONS.md).

- `REDESIGN-v3.md`: the v3 plan ("hosts and accounts") as the user approved
  it on 2026-10-18, before the build. Its "Decisions for you" section holds
  the four choices the user made.
- `KICKOFF_PROMPT.md`: the prompt that started the review and install session
  of the first build (2026-10-15).
- `HANDOFF-2026-10-15.md`: the first build's handoff notes, with review
  updates appended during that session.

How the requests between the v3 build groups were settled (phase B to phase
C) is in [../phaseB-requests/RESOLUTION.md](../phaseB-requests/RESOLUTION.md);
that folder stays next to the specs because code comments point to it.
